# Decisions

- Use public title "Sensi Master Coach" instead of exact "SENSI MASTER" to reduce Play Store confusion with existing apps.
- Start offline-first with no ads and no backend.
- Do not implement crosshair overlays in MVP.
- Use deterministic recommendations, not an LLM, for settings calculations.
- Keep creator presets source-gated. Empty or low-confidence creator datasets are better than fabricated content.
- Keep package name `com.sensimaster.coach`.
- Adopt a SENSIS-inspired matte black + red + gold theme across the app.
- In-app crosshair editor ships as a real tool in MVP; system overlay stays out of MVP.
- Mascot is a single blob shape with no mouth; eyes react to device gyroscope and blink.
- Keep every advertised feature honest reference material; never imply in-game automation.
