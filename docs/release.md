# Release

## Release Checklist

- Confirm versionCode and versionName.
- Confirm applicationId `com.sensimaster.coach`.
- Verify no signing keys or credentials are committed.
- Build debug APK.
- Build release AAB.
- Review Android permissions.
- Review Data safety and privacy policy.
- Confirm independent-app disclaimer.
- Confirm no game modification, automation, overlay, or cheat claims.
- Prepare screenshots and store copy around manual reference settings.

Publishing to Google Play requires explicit human confirmation.
