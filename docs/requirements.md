# Requirements

## MVP

- Onboarding creates the first player profile.
- Sensitivity generator recommends General, Red Dot, 2x, 4x, AWM/Sniper, and Free Look.
- Calibration Lab detects overshoot/undershoot and recommends small changes to one setting at a time.
- Profiles can be previewed, duplicated conceptually, and exported in a safe JSON-like text format.
- Tools include weapon guidance, HUD guidance, crosshair preview, device facts, performance notes, network notes, and guides.
- Creator presets section exists but contains only sourced or clearly sample/reference entries.
- Community and remote AI are labeled post-MVP/offline unavailable.

## Safety

- Minimum permissions.
- No overlay permission in MVP.
- No official Garena affiliation.
- No guaranteed gameplay outcome claims.
