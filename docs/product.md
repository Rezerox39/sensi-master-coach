# Product

## Name

Public title: Sensi Master Coach

Tagline: Your Personal FF Sensi Coach

## Positioning

An independent Free Fire companion and reference app that helps players find, test, understand, save, and refine manual sensitivity settings.

## Core Loop

Device -> Profile -> Generate -> Test -> Analyze -> Adjust -> Retest -> Save -> Improve

## Differentiation

- Honest reference-only guidance.
- Device/profile/history-aware recommendations.
- Controlled one-variable calibration adjustments.
- Offline-first coach experience.
- Original geometric mascot implemented in Compose.

## Non-Goals

- No game file or memory modification.
- No aim automation, macros, scripts, injection, or anti-cheat bypass.
- No fake FPS, ping, boost, or hardware claims.
- No unsourced creator settings.
